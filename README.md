# موقع سهر 💗

موقع تفاعلي متعدد الصفحات، فيه مواقف خفيفة، رسائل عتب وحب، واختبارات وأنيميشن.

## التشغيل

افتح `index.html` محليًا أو انشر المستودع على Vercel كموقع Static (Other Framework)، بدون Build Command أو قاعدة بيانات.

## الصفحات

`index.html` → `cases.html` → `loop.html` → `reaction.html` → `talk.html` → `quiz.html` → `promise.html` → `letter.html`.

توجد ملفات CSS وJavaScript في مجلد `assets/`.
